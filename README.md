PlacePicker 🌍

PlacePicker is an interactive travel wishlist app featuring a stylized globe and curated destination cards from around the world. Users can build their personal collection of dream destinations they want to visit or places they have already explored.

From the breathtaking Northern Lights and Machu Picchu to the serene Kerala Backwaters and Caribbean beaches, the app provides an engaging way to discover and organize unforgettable locations.

Features
🌎 Stylized globe inspired travel interface
📍 Select and save favorite destinations
🧭 Personal travel wishlist collection
🖼️ Beautiful destination imagery and descriptions
⚡ Smooth and responsive user experience
